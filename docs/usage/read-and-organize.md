# 阅读、标注与整理

这篇教程介绍从打开 PDF 到形成可复用笔记的一套工作流。

## 打开论文

在 Library 中选择论文即可打开论文标签页。也可以从文件树打开论文目录中的 PDF、Markdown 或图片。

顶部标签页支持同时打开多个文档。切换标签页不会重置 PDF 的滚动位置和缩放状态；使用 `⌥⌘←` / `⌥⌘→` 切换标签，使用 `⌘W` 关闭当前标签。

## 阅读 PDF

PDF 阅读器支持：

- 页码跳转；
- 适应宽度和整页显示；
- 大纲导航；
- `⌘F` 查找文本；
- 选中文本；
- 选择文本后的高亮、批注、提问和翻译。

扫描件没有文本层时，选词能力会受限；这不是 PDF 文件损坏。

## 高亮和批注

1. 在 PDF 中拖选一段文本。
2. 在选区菜单中选择颜色，创建高亮。
3. 如果需要写解释，继续添加批注。
4. 关闭浮层或切换页面，标注会保存到论文目录的 `marks/`。

批注不会写进原始 PDF，也不会自动追加到 `NOTES.md`。这样可以保留原始文件，并让标注数据可以被外部工具读取。

## 对选中文本提问

1. 选中需要理解的句子或段落。
2. 选择 **提问**。
3. 输入问题并发送。
4. 查看回答；需要时继续追问。

提问会把选中文本和页码作为上下文，并将结果保存到 `marks/`。PDF 划词提问使用设置中为 **PDF 划词提问** 配置的 Agent，不一定跟随右侧 Agent 面板当前选择的 Agent。

## 翻译

1. 选中原文。
2. 选择 **翻译**。
3. 选择目标语言或翻译服务。
4. 查看结果并保留需要的翻译记录。

翻译服务可以使用免费翻译服务，也可以使用已接入的 Agent。免费服务可能受限流或服务可用性影响；需要稳定结果时，优先配置自己的 Agent。

## 整理 NOTES.md

建议把论文的长期结论写进 `NOTES.md`，把短期阅读动作留在 `marks/`：

```markdown
# 这篇论文解决了什么问题

## 核心结论

## 方法

## 局限

## 与我的研究的关系
```

`NOTES.md` 是普通 Markdown 文件，可以在 Agentero、Obsidian、VS Code 或其它编辑器中继续编辑。

## 使用双链

在 Markdown 中使用 Obsidian 兼容的双链连接概念、论文和笔记：

```markdown
这篇工作扩展了 [[另一个论文]] 中的实验设置。
具体规则见 [[另一个论文#实验设置]]。
关键结论见 [[另一个论文#^summary]]。
```

输入 `[[` 后可从文件或 alias 候选中选择；继续输入 `#` 搜索标题，输入 `^` 搜索 block。存在同名文件时，候选和落盘文本使用 Vault 相对路径区分目标。

光标进入双链语法时，编辑器显示完整 `[[...]]`；光标离开后立即恢复链接样式。保存后，Agentero 更新 Backlinks 和 Graph。通过 Agentero 移动或重命名文件时，只改写原先明确解析到该目标的链接；可信的 Finder/Obsidian 外部改名按设置进入确认或自动修复。

## 嵌入 Vault 内容

在双链前添加 `!`，可将目标作为只读内容嵌入当前笔记：

```markdown
![[另一个论文]]
![[另一个论文#实验设置]]
![[另一个论文#^summary]]
![[assets/figure.png|480]]
![[papers/example/paper.pdf]]
```

支持的投影：

| 语法 | 显示内容 |
|---|---|
| `![[note]]` | 整篇 Markdown |
| `![[note#heading]]` | 该标题及其下属区段 |
| `![[note#^block-id]]` | block 所在行 |
| `![[image.png]]` | Vault 图片；alias 可写宽度或 `宽x高` |
| `![[document.pdf]]` | 内嵌 PDF 阅读组件 |

嵌入内容只读，顶部来源按钮和内部双链都可以点击跳转。光标进入 `![[...]]` 时显示源码，离开后恢复嵌入；普通文本自动保存不会重新加载未改变的嵌入目标。循环嵌入或超过 4 层的嵌套会显示有界提示。
