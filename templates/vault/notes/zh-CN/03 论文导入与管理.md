# 论文导入与管理

论文是 Agentero 的核心单元。每篇论文对应 `papers/` 下的一个独立文件夹。

## 论文文件夹结构

```text
papers/<id>/
├── NOTES.md          # 你的工作笔记
├── PAPER.md          # 派生可读正文（可选）
├── metadata.json     # catalog 投影
├── marks/            # PDF 高亮、批注、提问和翻译
└── source/           # PDF、TeX 或其它源文件
```

- `NOTES.md` 由你自由编辑。
- 没有 TeX 时，Agentero 会从 PDF 生成 `PAPER.md`。
- 不要手动编辑 `metadata.json`；通过 Library 或 Paper Info 面板更新元数据。

## 导入方式

### 魔棒入库

点击侧边栏的魔棒按钮，粘贴 arXiv ID、DOI 或 URL。Agentero 会下载元数据和 PDF 到新的论文文件夹。

### 本地 PDF

把 PDF 拖进文件树，或使用导入命令从本地文件创建论文文件夹。

### Zotero Connector

在设置 → 通用中开启 **Zotero Connector**，然后使用官方 Zotero 浏览器扩展将条目保存到当前 Vault。

### CLI

```bash
agentero paper import <source>
```

## 论文库（Library）

Library 表格展示 catalog 中的所有论文。你可以：

- 点击表头排序。
- 右键表头选择显示列并拖拽排序。
- 按标签筛选，或搜索标题、作者、摘要、标签子串。
- 点击 **Rescan** 补齐盘上有但 catalog 中没有的论文文件夹。

## 标签

在左下角的 **Info** 面板增删标签。标签保存在 `catalog.sqlite` 中，并以彩色 chip 显示在 Library 里。

## Download

如果侧边栏的论文栏显示 **下载** 图标，说明缺少 PDF 或可读正文。点击即可补齐缺失资源。
